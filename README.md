# Aula de Estudio

Pagina personal de estudio por cursos y modulos.

## Estructura

```
index.html        pagina principal
css/styles.css    estilos
js/config.js      ajustes (videos de YouTube activados)
js/videos.js      video de YouTube de cada modulo
js/data.js        contenido de los cursos
js/shell.js       terminal simulada de los laboratorios
js/app.js         logica de la pagina
assets/img/       imagenes
assets/videos/    videos propios (opcional)
```

## Videos

En cada sesion hay un cuadro para pegar el link de YouTube; el video se ve incrustado en la pagina. El link se guarda en el navegador.
